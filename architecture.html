IntentAgent — NLU

  • 规则层：关键词长度加权评分
  • LLM层：DeepSeek JSON分类（低置信度时）
  • 实体抽取：NPC / 地点 / 道具
  • 准确率 100%（20/20 测试集）
  • 0 LLM fallbacks on labeled set

ConsistencyAgent — 世界守卫

  • 规则①：USE_ITEM 道具必须在背包
  • 规则②：穗不能开口说话
  • 规则③：NPC 必须存活且在场
  • 规则④：知晓豚妖前不可提及
  • 规则⑤：贿赂需有铜钱
  • 准确率 100%（8/8 测试集）

RepairAgent — 叙事修复

  • 被一致性检查 FAIL 时触发
  • 生成叙事化拒绝，不暴露系统错误
  • state_delta = {} 修复回合不改变状态
  • 修复后仍走 Narrator → World → Choice

NarratorAgent — 核心叙事

  • system prompt 注入完整世界观设定
  • 输出：旁白 · 对话 · 暗线碎片 · state_delta
  • state_delta 包含数值变化 / 道具增减 / NPC更新
  • max_tokens=900，temperature=0.85

WorldAgent — 状态同步

  • 纯规则，零 LLM 调用（确定性）
  • 应用 NarratorAgent 输出的 state_delta
  • 检测地点变化 → 自动幕次切换
  • turn_history 滑动窗口（最近 8 轮）
  • 数值边界：relation 0–100，rep -50–50

ChoiceAgent — 选项生成

  • 生成 3–4 个方向各异的行动选项
  • 输入：地点 · 信任度 · 背包 · plot_flags
  • 避免与上轮选项重复
  • 选项差异度评估 0.986（目标≥0.4）
  • temperature=1.0（高创意度）
